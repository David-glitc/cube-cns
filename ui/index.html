On-chain registration not available yet

TheBox can reserve names in the index (shown as pending). Confirming a name on Cube Signet requires a contract register call, but the Cube node has no call command or Call API yet — only deploy, move, and liftup. When Cube adds Call support, on-chain registration will work; until then, pending does not mean registered on-chain.

TheBox CNS

TheBox is the public app for Cube Name Service on Bitcoin Signet — human-readable .cube names mapped to Cube account keys. This site indexes names and prepares register data; on-chain confirmation is not possible yet (see notice above). Your keys stay in the browser.

Connect your Cube identity

TheBox is a Signet name app — register and resolve .cube names via API. It does not run a shared Cube node in your browser.

Your keys (plain language)

  • nsec — private seed (like a password). Never share it. TheBox does not store it on the server.
  • Cube account — 64-character hex (your public identity on Cube Signet). This is what you import into TheBox.

Option B — Existing Cube node

What is Cube?

Cube is a Bitcoin virtual execution environment — smart contracts and accounts on Signet. TheBox is only the .cube name registry UI.
